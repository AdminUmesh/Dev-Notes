# Section-1 (Engineering Fundamental (25 Minutes))

# Equalizing Power

## 1. Problem statement

You are given `n` robots. Each robot has a power level stored in an
array called `power`.

In one minute, you can change the power of **one robot** by exactly 1: -
Increase its power by 1, or - Decrease its power by 1.

Find the **minimum number of minutes** required to make all robots have
the same power level.

## 2. Example

**Input**

``` text
power = [2, 5, 3, 6, 7, 1]
```

One optimal target power is `4`.

    Current power   Target power   Minutes needed
  --------------- -------------- ----------------
                2              4                2
                5              4                1
                3              4                1
                6              4                2
                7              4                3
                1              4                3
        **Total**                          **12**

**Output**

``` text
12
```

## 3. Easy approach: Use the median

The **median** is the middle value after sorting the numbers.

``` text
Original: [2, 5, 3, 6, 7, 1]
Sorted:   [1, 2, 3, 5, 6, 7]
```

There are six values, so the two middle values are `3` and `5`. Any
target between `3` and `5` gives the same minimum total. We can choose
`5`.

``` text
|2 - 5| = 3
|5 - 5| = 0
|3 - 5| = 2
|6 - 5| = 1
|7 - 5| = 2
|1 - 5| = 4

Total = 3 + 0 + 2 + 1 + 2 + 4
      = 12
```

Therefore, the minimum number of minutes is **12**.

> The median minimizes the sum of absolute differences between the
> values and a common target. The average does not always do this.

## 4. C# solution

The coding platform provides this method signature:

``` csharp
public static long equalize(List<long> power)
```

Complete it as follows:

``` csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Result
{
    public static long equalize(List<long> power)
    {
        // Step 1: Sort the power levels
        List<long> sortedPower = power.OrderBy(x => x).ToList();

        // Step 2: Find the middle element (median)
        int middle = sortedPower.Count / 2;
        long median = sortedPower[middle];

        // Step 3: Calculate the total number of minutes
        long totalMinutes = 0;

        foreach (long currentPower in power)
        {
            totalMinutes += Math.Abs(currentPower - median);
        }

        // Step 4: Return the minimum minutes
        return totalMinutes;
    }
}
```

For an even-sized array, this code selects the upper middle value. That
is valid: any value between the two middle values produces the same
minimum total.

## 5. How the code works

1.  `OrderBy()` sorts the power levels in ascending order.
2.  `Count / 2` gives the index of the upper middle element.
3.  That middle element is selected as the target power.
4.  `Math.Abs()` calculates how many one-unit changes each robot needs.
5.  The differences are added and returned.

The sorted copy requires `O(n)` additional space.

## 6. Practice cases

  Input                    Expected output
  ---------------------- -----------------
  `[2, 5, 3, 6, 7, 1]`                `12`
  `[1, 1, 1]`                          `0`
  `[1, 2, 3]`                          `2`
  `[1, 10]`                            `9`
  `[4]`                                `0`
