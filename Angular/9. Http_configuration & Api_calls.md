# HttpClient

`HttpClient` is Angular's service for communicating with backend APIs over HTTP.

  | HTTP method   | Purpose                 |
  | ------------- | ----------------------- |
  | `GET`         | Read data               |
  | `POST`        | Create data             |
  | `PUT`         | Replace/update data     |
  | `PATCH`       | Partially update data   |
  | `DELETE`      | Delete data             |

## 1. Configure HttpClient

For a standalone Angular application, configure `HttpClient` in `app.config.ts`:

``` typescript
import { ApplicationConfig } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';

export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient()
  ]
};
```

`provideHttpClient()` registers Angular's HTTP services with dependency injection.

## 2. Create a service

Keep API communication in a service rather than repeating HTTP calls in components.

``` bash
ng generate service services/user
```

### `services/user.service.ts`:

``` typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { User } from '../models/user.model';

@Injectable({
  providedIn: 'root'
})
export class UserService {
  private http = inject(HttpClient);
  private apiUrl = 'https://jsonplaceholder.typicode.com/users';

  // GET: Fetch all users
  getUsers(): Observable<User[]> {
    return this.http.get<User[]>(this.apiUrl);
  }

  // GET: Fetch one user
  getUserById(id: number): Observable<User> {
    return this.http.get<User>(`${this.apiUrl}/${id}`);
  }

  // POST: Create a user
  addUser(user: Omit<User, 'id'>): Observable<User> {
    return this.http.post<User>(this.apiUrl, user);
  }

  // PUT: Update a user
  updateUser(id: number, user: User): Observable<User> {
    return this.http.put<User>(`${this.apiUrl}/${id}`, user);
  }

  // DELETE: Delete a user
  deleteUser(id: number): Observable<void> {
    return this.http.delete<void>(`${this.apiUrl}/${id}`);
  }
}
```

### Understand the Code

| Code | Purpose |
|---|---|
| `@Injectable({ providedIn: 'root' })` | Makes the service available application-wide through dependency injection. |
| `inject(HttpClient)` | Gets an instance of Angular's `HttpClient`. |
| `http.get<T>()` | Sends a GET request and types the expected response. |
| `http.post<T>()` | Sends data to create a resource. |
| `http.put<T>()` | Sends data to replace/update a resource. |
| `http.delete<T>()` | Sends a DELETE request. |
| `Observable<T>` | Represents the asynchronous response stream. |
| `Omit<User, 'id'>` | Uses the `User` type without its `id` property. |

## 3. Call the API from a component

Example `app.component.ts`:

``` typescript

export class AppComponent {
  private userService = inject(UserService);

  users: User[] = [];
  loading = false;
  errorMessage = '';

  loadUsers(): void {
    this.loading = true;
    this.errorMessage = '';

    this.userService.getUsers().subscribe({
      next: (response) => {
        this.users = response;
        this.loading = false;
      },
      error: (error) => {
        console.error('API error:', error);
        this.errorMessage = 'Unable to load users.';
        this.loading = false;
      }
    });
  }
}
```

## 3. Understand subscribe()

Angular `HttpClient` methods return RxJS Observables. The HTTP request
is sent when you subscribe to the Observable.

``` typescript
this.userService.getUsers().subscribe({
  next: (response) => {
    console.log('Success:', response);
  },
  error: (error) => {
    console.log('Error:', error);
  },
  complete: () => {
    console.log('Request completed');
  }
});
```

  | Callback     | When it runs                                  |
  | ------------ | --------------------------------------------- |
  | `next`       | When response data is emitted.                |
  | `error`      | When the request fails.                       |
  | `complete`   | When the Observable completes successfully.   |

For a normal HTTP response, `HttpClient` emits the response and then
completes. If the request errors, the `error` callback runs instead.

## 4. POST example

``` typescript
addUser(): void {
  const newUser = {
    name: 'John',
    email: 'john@example.com'
  };

  this.userService.addUser(newUser).subscribe({
    next: (response) => console.log('User created:', response),
    error: (error) => console.error('Create failed:', error)
  });
}
```

## 5. PUT example

``` typescript
updateUser(): void {
  const updatedUser = {
    id: 1,
    name: 'John Updated',
    email: 'john.updated@example.com'
  };

  this.userService.updateUser(1, updatedUser).subscribe({
    next: (response) => console.log('User updated:', response),
    error: (error) => console.error('Update failed:', error)
  });
}
```

## 6. DELETE example

``` typescript
deleteUser(id: number): void {
  this.userService.deleteUser(id).subscribe({
    next: () => console.log('User deleted'),
    error: (error) => console.error('Delete failed:', error)
  });
}
```

## Important terms

| Term | Purpose |
|---|---|
| `HttpClient` | Angular service used to make HTTP requests. |
| `provideHttpClient()` | Registers/configures `HttpClient` in a standalone application. |
| `@Injectable()` | Marks a class for Angular dependency injection. |
| `inject()` | Retrieves a dependency from Angular's injector. |
| `Observable` | Represents an asynchronous stream of values. |
| `subscribe()` | Starts the HTTP request and listens for its result. |
| `next` | Handles successful response data. |
| `error` | Handles request failure. |
| `complete` | Handles successful Observable completion. |
| `GET` | Reads data. |
| `POST` | Creates data. |
| `PUT` | Replaces or updates a resource. |
| `PATCH` | Partially updates a resource. |
| `DELETE` | Deletes a resource. |

## Quick revision

**Q: What is HttpClient in Angular?**\
It is Angular's service for sending HTTP requests to backend APIs.

**Q: Where do we configure HttpClient in a standalone application?**\
Usually in `app.config.ts`, using `provideHttpClient()`.

**Q: Where should API calls be written?**\
Usually in injectable services, so HTTP logic can be reused by
components.

**Q: What does HttpClient return?**\
It returns an RxJS Observable.

**Q: When is an HttpClient request sent?**\
When its Observable is subscribed to.

**Q: What is the difference between POST and PUT?**\
POST commonly creates a resource; PUT commonly replaces or updates a
resource at a known URL.

**Q: What is CORS?**\
A browser security mechanism that controls whether a frontend from one
origin can access resources from another origin. The server must allow
the frontend origin.
