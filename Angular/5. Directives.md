# Directive in Angular?
Directives are classes that add behavior to HTML elements or change their appearance and structure.

In simple words:
directives tell Angular how an HTML element should behave.

### For example:
- Show or hide an element.
- Apply styles dynamically.
- Repeat elements using a loop.
- Respond to user interactions.

## Types of Directives
- **Component-** A directive with a template	@Component(...)
- **Structural-**	Change the DOM structure	*ngIf, *ngFor
- **Attribute-**	Change the appearance or behavior	[ngClass], [ngStyle], [ngModel]
- **Event Binding-**	(click), (submit), (ngSubmit)

## 1. Component (Built-in)
A component is actually a special directive with a view (template).

```ts
@Component({
  selector: 'app-hello',
  template: `<h1>Hello World</h1>`
})
export class HelloComponent {}
```

## 2. Structural Directive – changes the layout
These start with * and modify the DOM structure.

**ngIf**

Conditional rendering
```html
<h1 *ngIf="isLoggedIn">
  Welcome User!
</h1>
```

**ngFor** 

Loop through data
```html
<div *ngFor="let user of users">
  {{ user }}
</div>
```

**ngSwitch** 

Multiple conditions
```html
<div [ngSwitch]="role">
  <p *ngSwitchCase="'admin'">Admin User</p>
  <p *ngSwitchCase="'user'">Normal User</p>
  <p *ngSwitchDefault>Unknown User</p>
</div>
```

## 3. Attribute Directive – changes appearance/behavior
These don’t add/remove elements, but modify how they look or act.

**ngClass:** 

Dynamically apply CSS classes
```html
<p [ngClass]="{'active': isActive}">
  Hello Angular
</p>
```

**ngStyle:**

Dynamically apply inline styles
```html
<p [ngStyle]="{'color': isActive ? 'green' : 'red'}">
  Hello Angular
</p>
```

**ngModel:**

Two-way data binding
```html
<input [(ngModel)]="username">

<p>{{ username }}</p>
```

## Custom Directive Example (Attribute)
Suppose you want to highlight an HTML element when the mouse moves over it.

**Create it**
```bash
ng generate directive highlight
```

`highlight.directive.ts` this file created


**highlight.directive.ts**
```ts
import { Directive, ElementRef, HostListener } from '@angular/core';

@Directive({
  selector: '[appHighlight]',
  standalone: true
})
export class HighlightDirective {

  constructor(private element: ElementRef) {}

  @HostListener('mouseenter')
  onMouseEnter() {
    this.element.nativeElement.style.backgroundColor = 'yellow';
  }

  @HostListener('mouseleave')
  onMouseLeave() {
    this.element.nativeElement.style.backgroundColor = 'white';
  }
}
```

**Use in Html**

<p appHighlight>
  Move your mouse here!
</p>
