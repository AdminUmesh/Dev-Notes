# React Hooks

## 1. What are Hooks?

A **Hook** is a special function provided by React that lets a functional component use React features.

For example, a normal JavaScript variable does not maintain its value when a component re-renders:

```jsx
function Counter() {
  let count = 0;
}
```

With `useState`:

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```

Now React can **remember the value** and **update the UI** when it changes.

### Simple definition

> **Hooks = special React functions that give React features to functional components.**

---

# 2. Main React Hooks

React provides many built-in Hooks. You don't need to learn all of them at once.

The most important ones are:

* `useState`
* `useEffect`
* `useContext`
* `useRef`
* `useMemo`
* `useCallback`
* `useReducer`
* `useLayoutEffect`
* `useId`

---

## 3. useState

`useState` is used to **store and change data** in a component.

```jsx
const [name, setName] = useState("");
```

Example:

```jsx
const [count, setCount] = useState(0);

setCount(count + 1);
```

### Simple meaning

> **useState = remember and change data**

---

## 4. useEffect

`useEffect` is used to perform a task **after rendering** or when some value changes.

```jsx
useEffect(() => {
  console.log("Component rendered");
}, []);
```

Common uses:

* API calls
* Timers
* Event listeners
* Working with external systems

### Simple meaning

> **useEffect = perform a task after rendering or when data changes**

---

## 5. useContext

`useContext` is used to get **shared data** without passing it through every component.

For example:

```text
App
 └── User
      └── Profile
           └── Button
```

Without Context:

```text
App → User → Profile → Button
```

You may need to pass the `user` data through every component.

With Context, the `Button` can get the shared data directly:

```jsx
const user = useContext(UserContext);
```

### Simple meaning

> **useContext = get shared data**

---

## 6. useRef

`useRef` is mainly used for:

1. Accessing a DOM element
2. Storing a value without causing a re-render

Example:

```jsx
const inputRef = useRef(null);
```

Access the input:

```jsx
inputRef.current?.focus();
```

### Simple meaning

> **useRef = keep a value or access a DOM element without re-rendering**

---

## 7. useMemo

`useMemo` is used to **remember a calculated value**.

```jsx
const total = useMemo(() => {
  return price * quantity;
}, [price, quantity]);
```

React can reuse the previous result until `price` or `quantity` changes.

### Simple meaning

> **useMemo = remember a calculated value**

It is mainly useful for expensive calculations or when you need stable references.

---

## 8. useCallback

`useCallback` is used to **remember a function** between renders.

```jsx
const handleClick = useCallback(() => {
  console.log("Clicked");
}, []);
```

### Simple meaning

> **useCallback = remember a function**

---

## 9. useReducer

`useReducer` is useful when state logic becomes more complicated than a simple `useState`.

```jsx
const [state, dispatch] = useReducer(reducer, initialState);
```

For example, a shopping cart may have actions like:

```text
ADD_ITEM
REMOVE_ITEM
UPDATE_ITEM
CLEAR_CART
```

### Simple meaning

> **useReducer = manage complex state logic**

---

## 10. useLayoutEffect

`useLayoutEffect` is similar to `useEffect`, but it runs **before the browser paints the updated UI**.

```jsx
useLayoutEffect(() => {
  // code
}, []);
```

It is less commonly needed.

### Simple meaning

> **useLayoutEffect = run an effect before the screen is painted**

---

## 11. useId

`useId` generates a unique ID.

It is especially useful for connecting labels and form inputs.

```jsx
const id = useId();
```

Example:

```jsx
<label htmlFor={id}>Name</label>
<input id={id} />
```

### Simple meaning

> **useId = generate a unique ID**

---

# 12. Quick Hook Reference

| Hook              | Simple meaning                 |
| ----------------- | ------------------------------ |
| `useState`        | Remember and change data       |
| `useEffect`       | Perform a task after rendering |
| `useContext`      | Get shared data                |
| `useRef`          | Keep a value / access DOM      |
| `useMemo`         | Remember a calculated value    |
| `useCallback`     | Remember a function            |
| `useReducer`      | Manage complex state           |
| `useLayoutEffect` | Run effect before painting     |
| `useId`           | Generate a unique ID           |

# Custom Hooks

## 13. What are Custom Hooks?

A **Custom Hook** is a reusable JavaScript function that uses React Hooks.

A Custom Hook normally starts with `use`.

For example:

```jsx
function useCounter() {
  const [count, setCount] = useState(0);

  return { count, setCount };
}
```

Now the logic can be reused in different components.

### Simple definition

> **Custom Hook = your own reusable Hook for sharing logic.**

---

# 14. Why Use Custom Hooks?

Custom Hooks help you:

* Reuse logic
* Avoid duplicate code
* Keep components clean
* Separate logic from UI
* Make code easier to maintain

---

# 15. Rules of Custom Hooks

A Custom Hook:

* Must start with `use`
* Can use other Hooks
* Must follow the Rules of Hooks

Examples:

```text
useCounter()
useUsers()
useAuth()
useCustomer()
```

---

# 16. Custom Hook Example

### Create a Custom Hook

```jsx
import { useState } from "react";

function useCounter() {
  const [count, setCount] = useState(0);

  const increment = () => {
    setCount(count + 1);
  };

  const decrement = () => {
    setCount(count - 1);
  };

  return {
    count,
    increment,
    decrement
  };
}
```

### Use the Custom Hook

```jsx
function Counter() {
  const { count, increment, decrement } = useCounter();

  return (
    <>
      <h1>{count}</h1>

      <button onClick={increment}>+</button>

      <button onClick={decrement}>-</button>
    </>
  );
}
```

The component doesn't need to know how the counter logic works.

It simply uses:

```jsx
const { count, increment, decrement } = useCounter();
```

---

# 17. Built-in Hooks vs Custom Hooks

### Built-in Hook

Provided by React:

```jsx
useState()
useEffect()
useRef()
useContext()
```

### Custom Hook

Created by us:

```jsx
useCounter()
useUsers()
useAuth()
useCustomer()
```

---

# 18. Easy Way to Remember

Think of Hooks as **tools** that give your component extra abilities:

```text
useState
   ↓
Remember data

useEffect
   ↓
Perform a task

useRef
   ↓
Remember a value / access DOM

useContext
   ↓
Get shared data

useMemo
   ↓
Remember a calculation

useCallback
   ↓
Remember a function

useReducer
   ↓
Manage complex state

Custom Hook
   ↓
Create your own reusable logic
```

## Important

`useState` and `useRef` are both **Hooks**.

For learning purposes, `useState` is usually learned early because understanding **state** is fundamental to React.

A good learning order is:

```text
useState
   ↓
useEffect
   ↓
useRef
   ↓
useContext
   ↓
useMemo
   ↓
useCallback
   ↓
useReducer
   ↓
Custom Hooks
```
